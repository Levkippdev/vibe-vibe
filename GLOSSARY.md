# GLOSSARY — правила перевода и словарь терминов

Единый источник правды для русской локализации (`docs/ru/`). Обязателен для каждой сессии перевода. Дополняется по мере работы: спорный термин → решение → запись сюда.

## Правила перевода

### Что переводим

- Нарратив: абзацы, списки, таблицы, цитаты, подписи.
- Заголовки (`##`, `###`), текст «Next section →» в конце урока.
- Frontmatter: значения `title`, `description`, `chapter`.
- Комментарии внутри кода — можно переводить, если они объясняют смысл.
- Тексты заданий («впишите сюда…», «скопируйте шаблон…»).

### Что НЕ переводим (оставляем на английском)

- `order`, пути, имена файлов — зеркалируем `docs/en/...` → `docs/ru/...` **точно**.
- Термины индустрии: prompt, commit, deploy, localhost, API, PRD, MCP, skill, token, workflow, builder, feedback и т.п. При **первом** упоминании в главе — короткое русское пояснение в скобках, если термин может быть новым для ученика.
- Код: идентификаторы, строки кода, команды (`pnpm install`, `git clone`, `docker compose up -d --build`).
- Внешние URL, названия продуктов (ChatGPT, Claude, Cursor, Vercel, GitHub).
- Скриншоты и ссылки на картинки — как есть.

### Ссылки

- Внутренние `en/...` → `ru/...` (относительные пути внутри переведённого файла).
- Ссылки на непереведённые страницы: оставить путь `ru/...` — VitePress покажёт 404 только если файла нет; Better: сослаться на en-версию с пометкой, либо пока не ссылаться. Решение по каждому случаю фиксируем в PROGRESS.

### Компоненты Vue в уроках

- Basic: `<BasicEditionUpdateBox />` заменяем русским markdown-блоком (update-notice).
- Advanced: встроенные компоненты сохраняем как есть (их китайский UI — backlog после нарратива).

## Стиль

- Обращение на «вы» (в учебных текстах — допустимо «вы» строчными).
- Короткие абзацы, живой язык, без канцелярита; не дословный, а смысловой перевод.
- «Переведи идею, не буквы»: если английская фраза звучит по-русски неестественно — переформулируй, сохранив смысл.
- Англицизмы, укоренившиеся в IT-русском, — как есть (деплой допускается в устоявшемся контексте «деплой/развертывание»; в остальном следуй словарю).

## Спорные случаи (решения)

| Фраза оригинала | Принятый перевод |
|---|---|
| "mental shift from coder to commander" | «ментальный переход: от Coder к Commander» |
| "from zero to shipped" | «от нуля до релиза» |
| "bring your ideas to life" | «воплотите свои идеи» |
| "AI Creation for Everyone" | «AI-творчество для каждого» |
| "unsolicited contribution" | (не используется в нарративе) |
| "vibe coding revolution" | «революция Vibe Coding» |
| "spec-driven development" | «spec-driven разработка» |
