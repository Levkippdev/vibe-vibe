# Vibe Vibe — AI-творчество для каждого

> Открытый учебный проект для тех, кто хочет превращать идеи в настоящие продукты с помощью AI.
> От «у меня есть идея» до «я выпустил работающий продукт»: Vibe Vibe помогает новичкам, builder'ам и разработчикам учиться на реальных проектах.

- Сайт проекта: [www.vibevibe.cn](https://www.vibevibe.cn)
- Основной язык сайта: китайский
- Английская версия: [/en/](https://www.vibevibe.cn/en/)
- Русская версия: [/ru/](https://www.vibevibe.cn/ru/) — нарратив переведён, термины и код — на английском

## Core Idea

Vibe Vibe вдохновлён идеей **Andrej Karpathy** о Vibe Coding: переход от ручного написания каждой строки к сотрудничеству с AI через ясные цели, контекст, review и итерации.

На практике этот проект — не только про «AI-программирование». Он про то, как использовать AI, чтобы:

- превращать идеи в работающие продукты
- быстро собирать прототипы и учиться на создании
- получить достаточный технический рычаг, чтобы продолжать итерации и выпускать

## Для кого этот проект

## Self-Hosted Deployment

Если вы хотите развернуть сайт в локальной или закрытой сети, в этом репозитории уже есть готовые `Dockerfile` и `docker-compose.yml`:

```bash
docker compose up -d --build
```

Адрес по умолчанию: `http://localhost:1024`.

Полные варианты развертывания, хостинг статических файлов и заметки об offline-окружении — в [руководстве по деплою](./docs/deployment/index.md).

## Структура проекта

В Vibe Vibe четыре больших раздела:

| Раздел | Что покрывает | Кому подходит |
| --- | --- | --- |
| **Основы (Fundamentals)** | Дружелюбный путь новичка: от идеи до первого работающего проекта | Новички и те, кто создаёт впервые |
| **Продвинутый курс (Advanced)** | Full-stack delivery, архитектура, deployment, коллаборация и инженерные привычки | Разработчикам, которым нужен более системный workflow |
| **Практика (Practice)** | Практические кейсы для разных аудиторий и задач | Тем, кто учится через создание |
| **Статьи (Articles)** | Отобранные материалы, тренды и чтение для углубления | Тем, кто учится непрерывно |

## Чему здесь можно научиться

- как описывать идеи достаточно ясно, чтобы AI мог их выполнить
- как итерировать, не дожидаясь идеальной первой версии
- как пройти путь от прототипа через локальный проект к деплою
- как развивать продуктовое чутьё, а не только знакомство с инструментами
- как продолжать учиться full-stack-разработке на реальных кейсах
