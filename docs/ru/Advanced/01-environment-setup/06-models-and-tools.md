## Базовые понятия

### AI-модели

**AI-модели** отвечают за понимание намерений и генерацию контента. Например, на вопрос «как сделать функцию логина» модель анализирует запрос и возвращает кодовое решение.

| Категория | Представители |
|------|---------|
| **Китайские** | [GLM](https://open.bigmodel.cn/) (Zhipu), [DeepSeek](https://www.deepseek.com/), [Kimi](https://kimi.moonshot.cn/) (Moonshot), [Doubao](https://www.doubao.com/) (ByteDance), [MiniMax](https://www.minimaxi.com/) |
| **Международные** | [GPT](https://openai.com/) (OpenAI), [Gemini](https://gemini.google.com/) (Google), [Claude](https://claude.ai/) (Anthropic) |

**Инструменты** отвечают за выполнение конкретных действий: чтение файлов, запуск команд, коммит кода. Инструментам нужно подключение к модели, чтобы работать.

::: tip Chatbox vs Tool Workflow

Обычно пользуясь AI, вы, возможно, болтаете в веб-чате:

| Режим Chatbox | Режим Tool Workflow |
|-----------|-----------|
| Можно только болтать, нельзя оперировать файлами | Может напрямую читать и писать файлы в вашем проекте |
| Копируете код и вставляете сами | AI меняет код автоматически |
| Команды запускаете сами | AI выполняет команды автоматически |
| Хорош для вопросов и обучения | Хорош для реальной разработки |

**AI-инструменты кодинга = мозг AI + руки и ноги**. Модель — это мозг, инструменты — руки и ноги. С одним мозгом без рук вы можете только копировать код; с руками и ногами AI реально может делать работу за вас.

:::

| Тип | Представители | Особенности |
|------|---------|------|
| **CLI-инструменты** | Claude Code | Работают в командной строке, без графического интерфейса |
| **IDE-инструменты** | Cursor, Windsurf, Trae | Графический интерфейс, визуальные операции |


::: tip CLI vs IDE: как выбрать?

| | CLI-инструменты | IDE-инструменты |
|---|---------|---------|
| **Стиль взаимодействия** | Текстовая беседа в командной строке | Графический интерфейс + беседа |
| **Ощущения** | Чисто и сфокусированно, без отвлечений | Визуально и интуитивнее |
| **Гибкость** | Высокая, легко встраиваются в скрипты | Средняя, ограничена интерфейсом |
| **Лучше всего для** | Рекомендованы в этом туториале, серверная разработка | Разработчики, предпочитающие GUI |

**Ключевые способности одинаковы**: и те и другие могут напрямую оперировать файлами проекта, запускать команды и работать с Git. Этот туториал рекомендует CLI-инструменты (например, Claude Code), потому что они простые, мощные и лучше подходят для изучения основ AI-кодинга.

::: tip Совместное использование: best practice

**Откройте terminal внутри вашей IDE и запускайте CLI-инструменты там** — это предпочитаемый сетап многих разработчиков:

- Слева VS Code/Trae или другой редактор для просмотра файлов
- В terminal внизу — Claude Code или другой CLI-инструмент, помогающий менять код
- Смотрите структуру файлов, пока CLI-инструмент делает работу

Так вы получаете и визуальное удобство IDE, и мощь CLI-инструментов. Разумеется, рекомендуется всегда использовать одну и ту же AI-модель, чтобы контекст оставался консистентным.

:::

::: tip Связь IDE и VS Code

Большинство AI-IDE построено на **VS Code** (например, Cursor, Windsurf, Trae), поэтому интерфейс и паттерны взаимодействия схожи, расширения VS Code в целом совместимы, а кривая обучения очень пологая.

:::

::: tip Преимущества Claude Code

- **Публично доступен**: опубликован в npm registry, без региональных ограничений

- **Мощный workflow**: операции с файлами, поиск по коду, интеграция с Git и коллаборация sub-агентов

## Настройка модели GLM

Если вы уже настроили модель GLM по [1.0 Quick Start](./00-quick-start.md), этот раздел можно пропустить.

### Шаг 1: Купите Coding Package

Зайдите на [Zhipu AI Open Platform](https://open.bigmodel.cn/), купите официальный coding package и получите API Key.

::: tip Что такое API Key

API Key — это «пропуск» для вызова сервисов больших моделей. Он служит вашим идентификационным креденшелом при общении с серверами Zhipu AI.

:::

### Шаг 2: Автоматическая настройка

```bash
npx @z_ai/coding-helper
# Введите полученный API Key; инструмент автоматически завершит всю настройку
```

## FAQ

### Q: Обязательно ли использовать AI-редактор?

Да, это центральная идея туториала. Подход Vibecoding построен на AI-native разработке. Вы можете выбрать любой AI-IDE (Cursor/Windsurf/Trae и др.) или использовать CLI-инструмент Claude Code.

### Q: В чём разница между Cursor и VS Code?

Cursor — это AI-усиленная версия VS Code. В VS Code AI-расширения ставятся вручную, а Cursor глубоко интегрирует AI-возможности. Если вы уже знакомы с VS Code, перейти на Cursor легко.

## Ключевая философия

**Чтобы хорошо работать, надо сначала наточить инструменты**.

**Принципы выбора инструментов**:

1. **AI-native в первую очередь**: современная разработка зависит от AI
2. **Кроссплатформенность**: инструменты должны работать и на Mac, и на Windows
3. **Низкая кривая обучения**: избегайте чрезмерно сложных инструментов
4. **Активное сообщество**: документация и регулярные обновления важны

**Минимальный сетап**: Claude Code + GLM + terminal + браузер
