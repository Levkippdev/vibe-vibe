# 2.0 Рекомендуемая конфигурация

Это поможет вам быстро настроить эффективное окружение AI-кодинга. Убедитесь, что Claude Code уже установлен.

## 1. Установите плагины

> Подробное знакомство с плагинами — в разделе Advanced\02-ai-tuning-guide\03-mcp-and-skills.md.

Откройте Claude и введите `/plugin`, чтобы открыть магазин плагинов.

![image-20260203183832193](/images/Advanced/image-20260203183832193.png)

Клавишами ↑ и ↓ переключайте плагины для установки, Space — выбрать, `i` — установить. Некоторые плагины при установке открывают страницу браузера для входа — просто следуйте подсказкам.

![image-20260203184020360](/images/Advanced/image-20260203184020360.png)

### Рекомендуемые плагины

Рекомендуем установить следующие официальные плагины. Также можно выбрать нужные по описаниям:

| Плагин | Описание |
|---------|---------|
| code-review | Ревью кода |
| code-simplifier | Упрощение кода |
| commit-commands | Команды commit |
| context7 | Поиск по документации библиотек |
| feature-dev | Визард разработки функций |
| frontend-design | Frontend UI-дизайн |
| github | Операции с GitHub |
| playwright | Автоматизация браузера |
| pr-review-toolkit | Наб инструментов ревью PR |
| pyright-lsp | Языковой сервер Python |
| supabase | База данных Supabase |
| TypeScript-lsp | Языковой сервер TypeScript |

## 2. Установите CC-SWITCH

Установите [CC-SWITCH](https://github.com/farion1231/cc-switch) для управления несколькими провайдерами AI-моделей, MCP и Skills.

### Для пользователей Windows

Скачайте последнюю версию с официальной страницы [Releases](https://github.com/farion1231/cc-switch/releases) или быстро скачайте установщик по ссылке ниже:

<https://ghfast.top/https://github.com/farion1231/cc-switch/releases/download/v3.10.3/CC-Switch-v3.10.3-Windows.msi>

### Для пользователей macOS

Откройте Terminal и установите через Homebrew:

```bash
brew tap farion1231/ccswitch
brew install --cask cc-switch
```

### Для пользователей Linux

Обратитесь к [cc-switch/README_ZH.md](https://github.com/farion1231/cc-switch/blob/main/README_ZH.md) для установки.

## 3. Базовая настройка

Скачав и установив, откройте CC-SWITCH. Кликните плюс в правом верхнем углу для управления провайдерами. Импортировав разные модели, выберите провайдера и введите соответствующий API Key — и можно пользоваться.

| Главный экран                                                   | Добавить провайдера                                                   |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| [![Main Interface](https://github.com/farion1231/cc-switch/raw/main/assets/screenshots/main-zh.png)](https://github.com/farion1231/cc-switch/blob/main/assets/screenshots/main-zh.png) | [![Add Provider](/images/Advanced/add-zh.png)](https://github.com/farion1231/cc-switch/blob/main/assets/screenshots/add-zh.png) |

### Переключение провайдеров

- **Главный экран**: выберите провайдера → «Enable»
- **Системный трей**: кликните имя провайдера напрямую (вступает в силу сразу)

### Перезапустите приложение

Перезапустите terminal или клиент Claude Code / Codex / Gemini, чтобы изменения применились.

## 4. Управление MCP

Кликните кнопку «MCP» в правом верхнем углу, чтобы войти в интерфейс управления MCP. Кнопкой Import Existing можно импортировать и просмотреть MCP, установленные через плагины:

![image-20260203185306838](/images/Advanced/image-20260203185306838.png)

Если вы не установили плагин context7, здесь можно кликнуть правый верхний угол и добавить MCP-сервер context7.

> После установки введите usecontext7 во время беседы — и AI вызовет плагин context7 для поиска по официальной документации, повышая точность генерируемого кода.

![image-20260203184852968](/images/Advanced/image-20260203184852968.png)



## 5. Управление Skills

Кликните кнопку «Skills» в правом верхнем углу, чтобы войти в интерфейс управления skills:

- **Обзор Skills**: автоматическое сканирование преднастроенных repository GitHub (официальные Anthropic, ComposioHQ, сообщество и др.)
- **Кастомные repository**: поддержка добавления своих (включая сканирование подкаталогов)
- **Установка Skills**: кликните «Install» — установка одним кликом в `~/.claude/skills/`
- **Удаление Skills**: кликните «Uninstall» — безопасное удаление с очисткой состояния
- **Управление repository**: добавление/удаление кастомных GitHub-repository
