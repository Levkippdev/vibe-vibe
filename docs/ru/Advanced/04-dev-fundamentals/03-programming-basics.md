# 4.3 Как читать AI-сгенерированный код 🟢

> **Прочитав этот раздел, вы получите:**
>
> - Понимание четырёх базовых концепций: переменные, функции, условия и циклы
> - Способность читать AI-сгенерированный код и понимать его логику
> - Навык описания требований AI через псевдокод
> - Понимание, что одна функциональность реализуется разными способами

> Все языки программирования, как бы ни различался синтаксис, строятся на нескольких базовых концепциях.

---

## Введение

Техдокументация описывает, что система должна делать, но финальная реализация — код. Вам не нужно писать каждую строку самому, но нужно понимать базовую логику кода: читать AI-сгенерированный код, знать, что он делает, и troubleshot'ить при сбоях.

Языков программирования сотни, у каждого свой синтаксис, но все они разделяют несколько общих базовых концепций. Понимание этих концепций — как изучение «алфавита» чтения кода.

---

## Четыре базовых кирпичика кода

<CodeConceptVisualizer />

Когда вы просите AI сгенерировать код, он по сути комбинирует четыре базовых элемента. Понимание этих концепций поможет читать код и знать, что он делает.

### Переменные: контейнеры для данных

**Переменная** — контейнер для хранения данных. Представьте коробку с этикеткой: данные кладутся внутрь коробки, этикетка — имя переменной.

Например, `let username = "John"` создаёт коробку с именем `username` и «John» внутри. Позже это значение можно извлечь в любой момент или заменить содержимое коробки чем-то другим.

Переменные позволяют коду «помнить» информацию. Статус логина юзера, товары в корзине, заголовок статьи — всё это данные, хранящиеся в переменных.

### Функции: переиспользуемые блоки инструкций

**Функция** — переиспользуемый блок инструкций. Если вы пишете похожий код раз за разом, упакуйте его в функцию.

Функция принимает ввод (параметры), выполняет операцию и возвращает вывод. Например, функция расчёта полной цены товара:

- Ввод: цена за единицу, количество
- Процесс: цена × количество
- Вывод: полная цена

Определив функцию, для расчёта полной цены достаточно вызвать её с разными параметрами, не переписывая логику вычислений.

### Условия: развилки на дороге

**Условие** позволяет программе выполнять разные действия в зависимости от ситуации.

```
if (userIsLoggedIn) {
  showWelcomeMessage
} else {
  showLoginButton
}
```

Это условное выражение: программа решает, какой блок кода исполнить, по условию «залогинен ли юзер». Это как развилка: программа выбирает путь по условию.

### Циклы: сила повторения

**Цикл** позволяет программе повторять определённые операции.

Например, для отправки email 1000 юзерам не нужно писать код отправки 1000 раз. Достаточно одного цикла: «для каждого юзера в списке отправить email».

Суть цикла: **коротким описанием закрывать большой объём повторяющейся работы**.

## Turing-полнота: сила этих четырёх кирпичиков

Эти четыре концепции — переменные, функции, условия и циклы — фундамент **Turing-полноты**. Это значит: любая вычислимая проблема решается комбинациями этих четырёх элементов. Каждое приложение в вашем телефоне — калькулятор, WeChat, Taobao, Douyin — под капотом построено на разных комбинациях этих четырёх элементов.

От простых калькуляторов до сложного искусственного интеллекта, от web-форм до операционных систем — всё внутри построено из разных комбинаций этих четырёх концепций.

Читая код, старайтесь идентифицировать эти четыре элемента:

- Где хранятся данные? → **Переменные**
- Где инкапсулированы операции? → **Функции**
- Что исполняется при каких условиях? → **Условия**
- Что повторяется? → **Циклы**

## Псевдокод: мост для разговора с AI

Поняв базовые кирпичики кода, вы можете читать простую кодовую логику. Но важнее — использовать эти концепции для описания AI желаемой функциональности. Для этого и нужен псевдокод.

**Псевдокод** — способ выражения идей между естественным языком и формальным кодом. Он использует логические структуры программирования (условия и циклы) для описания требований, не следуя какому-либо конкретному синтаксису.

Например, для AI-помощи в написании функции логина юзера опишите её псевдокодом:

```
Когда юзер кликает кнопку логина:
    Получить email и пароль из полей ввода
    Проверить, валиден ли формат email
    Если формат верен:
        Отправить запрос на сервер для верификации
        Если верификация успешна:
            Редирект на главную страницу
        Иначе:
            Показать «Неверный пароль»
    Иначе:
        Показать «Неверный формат email»
```

Такое описание требований яснее плоского естественного языка, и при этом не требует освоения конкретного синтаксиса. AI отлично понимает псевдокод и помогает конвертировать его в формальный код.

## Алгоритмическое мышление: почему одна функциональность — разный код

Описывая требования псевдокодом, AI может предложить разные подходы реализации. Все они достигают одной функциональности, но шаги различаются.

Например: найти конкретный email среди 1000 юзеров.

**Подход 1**: проверять по одному. В худшем случае придётся проверить все 1000.

**Подход 2**: если юзеры отсортированы по email, начать с середины. Если целевой email позже — проверять только вторую половину, повторяя процесс. Так нужно максимум 10 проверок.

Оба подхода завершают задачу, но второй требует меньше шагов. Прося AI сгенерировать код, при больших объёмах данных просто напомните: «Объём данных большой — используй эффективный метод поиска» — AI поймёт, о чём вы.
