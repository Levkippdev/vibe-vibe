# 5.1 AI-инструменты дизайна

> **Цель раздела**: понять позиционирование и сценарии использования мейнстримных AI-инструментов дизайна, научиться выбирать правильный инструмент под сценарий и использовать их вместе с Claude Code.

На рынке много AI-инструментов, созданных специально для UI/UX. У каждого свои сильные стороны, и разумная комбинация заметно повышает эффективность работы.

::: tip Workflow

Используйте эти инструменты для **генерации первичного UI**, а Claude Code пусть берёт **интеграцию и модификации**. Рекомендуемый флоу: создать прототип инструментом дизайна → скопировать код в проект → использовать Claude Code для интеграции бизнес-логики и тонкой настройки.

:::

## Google AI Studio — платформа разработки AI-приложений (настоятельно рекомендуется)

Платформа разработки AI-приложений Google умеет использовать модели Gemini для генерации полных web-приложений, включая UI. Можно считать её онлайн-версией Claude Code от Google — просто откройте в браузере и работайте, локальная настройка не нужна.

![image-20260222173132952](/images/Advanced/image-20260222173132952.png)

**Лучше всего для**:

- Быстрого прототипирования AI-приложений
- Проектов с интеграцией моделей Gemini
- Единого workflow от дизайна до deploy
- Бесплатных юзеров

Visit: [aistudio.google.com](https://aistudio.google.com/apps)

## Google Stitch — AI-прототипирование дизайна

AI-инструмент UI-прототипирования от Google генерирует полные UI-мокапы из текстовых описаний или скетчей.

![image-20260222173221042](/images/Advanced/image-20260222173221042.png)

**Лучше всего для**:

- Проектирования layout'ов страниц с нуля
- Когда нужны дизайн-мокапы, а не код (мокап — то, что можно смотреть, но нельзя запустить; код — программа, которую можно запустить напрямую; Stitch даёт первое)
- Быстрой валидации визуального направления продуктовой идеи
- Бесплатного использования

Visit: [stitch.withgoogle.com](https://stitch.withgoogle.com/)

![image-20260227000703458](/images/Advanced/image-20260227000703458.png)

## Figma — стандартный инструмент в дизайне

Figma — инструмент №1 профессиональных дизайнеров, и теперь она включает и AI-ассистированные функции. Она не генерирует код напрямую, но помогает создавать точные дизайн-мокапы. Если у вас чёткое представление, как должна выглядеть страница, но не получается описать словами — Figma станет вашим холстом: нарисуйте сначала, затем AI напишет код по нему.

![image-20260222180858852](/images/Advanced/image-20260222180858852.png)

**Лучше всего для**:

- Дизайн-мокапов с пиксельной точностью
- Коллоборативного командного дизайна (дизайнеры + разработчики)
- Дизайн-систем и спецификаций компонентов

**Как это работает с Claude Code**:

Claude Code может подключаться напрямую к Figma (через плагин-протокол MCP). После настройки достаточно сказать AI:

> «Реализуй эту страницу по Figma-дизайну»

AI прочитает информацию дизайна в Figma (цвета, отступы, шрифты) и сгенерирует соответствующий код.

![image-20260222181216119](/images/Advanced/image-20260222181216119.png)

Visit: [figma.com](https://www.figma.com/)

## Пусть AI поможет выбрать инструмент

Не уверены, что использовать? Просто спросите AI напрямую:

> «Я хочу построить страницу товара для e-commerce сайта: карусель картинок, отображение цены и кнопка "в корзину". Какой инструмент — самый быстрый вариант?»

AI порекомендует самый подходящий инструмент и workflow под ваши конкретные потребности.

---

::: tip Инструменты — лишь средство

AI-инструменты помогают быстро генерировать интерфейсы, но **продуктовое дизайн-мышление** остаётся вашим ключевым конкурентным преимуществом. Инструменты продолжат эволюционировать, но способность «понимать, что юзерам действительно нужно» никогда не устареет.

:::
