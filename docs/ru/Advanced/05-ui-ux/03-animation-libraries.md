# 5.3 Библиотеки анимаций и интеракций

> **Цель раздела**: понять позиционирование мейнстримных библиотек анимаций, научиться выбирать анимационное решение под потребности и освоить техники написания промптов для работы с AI.

Удачно поставленная анимация превращает страницу из «юзабельной» в «приятную». Но слишком много анимаций юзеров укачивает. Как говорят профи: «Хорошая анимация должна быть почти незаметна юзеру — она просто делает интеракции плавнее, не крадя внимание».

## Motion (бывший Framer Motion) — топ-выбор для React-анимаций

[Official Motion Examples | React, JS & Vue Animations](https://motion.dev/examples)

Motion (имя пакета `motion`, ранее `framer-motion`) — самая популярная библиотека анимаций в React-экосистеме, 30 000+ GitHub stars. Достаточно описать, «каким элемент должен быть в конце анимации», — и Motion вычислит промежуточные состояния за вас. Это вписывается в философию React: «описывай результат, а не шаги».

![image-20260222213320488](/images/Advanced/image-20260222213320488.jpg)

**Частые анимационные сценарии и промпты**:

| Эффект, который нужен | Скажите AI |
|------------|---------|
| Элемент появляется с fade-in | «Используй Motion, чтобы добавить fade-in анимацию этой карточке» |
| Пункты списка появляются по одному | «Используй staggerChildren из Motion, чтобы пункты списка плавно появлялись один за другим» |
| Drag-to-sort | «Используй компонент Reorder из Motion для реализации сортировки drag-and-drop» |
| Анимация перехода между страницами | «Используй AnimatePresence из Motion для создания переходов страниц» |
| Анимация по триггеру скролла | «Используй whileInView из Motion, чтобы запускать анимацию при входе элемента во viewport» |

## GSAP — профессиональный движок анимаций

[Homepage | GSAP](https://gsap.com/)

GSAP (GreenSock Animation Platform) — давний тяжеловес мира web-анимаций: экстремально сильная производительность и способность создавать самые сложные анимационные эффекты.

![image-20260222213406770](/images/Advanced/image-20260222213406770.png)

**Особенности**:

- Производительность best-in-class: без просадок кадров даже в сложных анимациях
- Поддержка timelines — можно выстраивать несколько анимаций по порядку, похоже на таймлайн видеоредактора: какая анимация играет первой, какая следующей, сколько задержки между ними
- Богатая экосистема плагинов: ScrollTrigger (триггеры по скроллу), Draggable (перетаскивание), MorphSVG (морфинг SVG)
- Не ограничен React; работает с любым фреймворком

**Лучше всего для**:

- Эффектных скролл-анимаций на маркетинговых лендингах
- Сложных SVG-анимаций и path-анимаций
- Анимационных последовательностей с точным контролем таймлайна
- Сценариев с экстремально высокими требованиями к производительности

**Примеры промптов**:

> «Используй ScrollTrigger из GSAP, чтобы создать эффект параллакс-скролла (как часто бывает на сайте Apple, где фон и передний план движутся с разной скоростью), с фоновой картинкой, скроллящейся медленнее контента»

> «Используй Timeline из GSAP, чтобы создать intro-анимацию: сначала плавно появляется логотип, затем заголовок выезжает слева, и в конце кнопка появляется с pop-эффектом»

## Three.js — максимальный инструмент 3D-эффектов

[Three.js – JavaScript 3D Library](https://threejs.org/)

Если хочется создавать 3D-эффекты в web, Three.js — выбор без альтернатив. В паре с React-обёрткой `@react-three/fiber` можно строить 3D-сцены React-компонентами.

## Легковесные анимационные решения

Не каждая анимация требует большой библиотеки. Для некоторых простых эффектов достаточно CSS:

| Эффект | Решение | Нужна ли библиотека? |
|------|------|-----------|
| Смена цвета кнопки при hover | CSS `transition` | Нет |
| Плавное появление/исчезание элемента | CSS `@keyframes` | Нет |
| Простой slide in/out | Tailwind CSS `animate-*` | Нет |
| Stagger-анимация пунктов списка | Motion | Да |
| Сложная скролл-анимация | GSAP ScrollTrigger | Да |
| 3D-эффекты | Three.js | Да |

**Примеры промптов**:

> «Добавь hover-эффект этой кнопке чистым CSS transition, не вводя никаких лишних библиотек»

> «Эта loading-анимация может просто использовать animate-spin из Tailwind; Motion тут не нужен»

## Правильное количество анимаций

**Меньше — значит больше**.

- Держите длительность анимаций в 200–500 мс: слишком быстро — юзер не разглядит, слишком медленно — ощущение лагов
- Анимации, запускаемые напрямую юзером (клик, hover), могут быть заметнее
- Автопроигрывающиеся анимации (при входе во viewport) должны быть тоньше
- На мобильных сокращайте анимации — экономия батареи и трафика
