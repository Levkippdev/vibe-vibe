# 5.5 Эффекты, делающие страницу «дорогой»

> **Цель раздела**: узнать частые эффекты, делающие страницу «дорогой» на вид, понять формулировки промптов для каждого и заставлять AI реализовывать их напрямую по мере необходимости.

Некоторые страницы мгновенно ощущаются «премиальными», даже если вы не можете объяснить почему. На деле они используют много стандартизированных high-end эффектов. Как говорит ветеран: «У всех этих эффектов есть имена. Зная имена, вы можете поручить их построение AI».

Каждый эффект включает live-превью и подходящий AI-промпт — готов к копированию и использованию напрямую.

Когда вы листаете сайт Apple, картинки и текст словно движутся с разной скоростью, создавая глубину — это работа эффектов скролла.

## Эффекты интеракций

Эффекты, с которыми юзеры взаимодействуют активно — перетаскивание, свайпы, hover — превращают страницу из той, что «смотрят», в ту, с которой «играют».

<InteractionEffects />

## Рекомендации по использованию

::: warning Меньше — значит больше
Используйте максимум 2–3 премиальных эффекта на одной странице. Попытка использовать всё = flashy-бардак.
:::

1. **Сначала функциональность, потом эффекты**. Эффекты усиливают опыт; они не спасают сломанный
2. **Осторожно на мобильных**. Сложные анимации могут лагать на телефонах
3. **Приоритет — производительность**. Если эффект замедляет страницу — убирайте без колебаний
4. **Анимация должна иметь смысл**. Каждая анимация должна что-то сообщать или направлять внимание — не просто выпендриваться
