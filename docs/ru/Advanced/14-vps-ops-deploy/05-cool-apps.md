# 14.5 Другие полезные приложения

> **Цель раздела**: открыть больше способов использования сервера — устанавливать разное практичное опенсорс-ПО через магазин 1Panel или Docker Compose.

Проект Сяомина задеплоен, домен подключён, HTTPS показывает тот успокаивающий зелёный замок. Он глянул на монитор ресурсов в дашборде 1Panel — CPU и памяти ещё с запасом. «Что ещё можно поставить?»

Старый мастер сказал: «Свой сервер — как собственный участок земли. Помимо основных культур (деплой проекта) можно посадить и что-нибудь интересное».

## Umami: веб-аналитика

**Строка-введение**: privacy-дружелюбный инструмент веб-аналитики и опенсорсная альтернатива Google Analytics.

**Зачем использовать**:

- Не отслеживает приватность юзеров, соответствует GDPR
- Чистый интерфейс, данные читаются с одного взгляда
- Self-hosted: данные полностью в ваших руках

**Способ установки**: поищите «Umami» в магазине 1Panel и поставьте одним кликом. В форме установки нужно заполнить имя, версию, порт (дефолт 3000), сервис базы (выберите установленный инстанс PostgreSQL или MySQL из dropdown), имя базы, юзера и пароль.

![image-20260303152245410](/images/Advanced/image-20260303152245410.png)

Когда Сяомин ставил Umami, в dropdown «Database Service» он увидел ранее установленный инстанс PostgreSQL. Выбрал его, ввёл имя базы `umami` и пароль, кликнул подтверждение. Через несколько секунд Umami заработал.

![image-20260303152328354](/images/Advanced/image-20260303152328354.png)

После установки добавьте свой сайт в дашборде Umami — он сгенерирует tracking-сниппет. Добавьте его в `<head>` вашего сайта:

```html
<script
  defer
  src="https://your-umami-url/script.js"
  data-website-id="your-website-id"
></script>
```

Сяомин добавил tracking-сниппет в конфигурацию `head` VitePress, пересобрал и передеплоил. Через несколько часов он снова открыл дашборд Umami — там уже было несколько визитов. Все — с его собственного тестирования, но видеть, как реально приходят данные, всё равно приятно.

Поставив Umami, Сяомин открыл его на следующий день: «Люди правда пользуются моим сайтом!» Наблюдать, как счётчик посетителей тикает с нуля — волнительнее любого console.log.

## n8n: автоматизация воркфлоу

**Строка-введение**: опенсорсная платформа автоматизированных воркфлоу, похожая на Zapier, но self-hosted.

**Что умеет**:

- Автоматически слать welcome-письма при регистрации новых юзеров
- Отправлять нотификации в WeChat/Feishu при новых GitHub Issue
- По расписанию забирать данные и генерировать отчёты
- Связывать разные API и строить автоматизированные процессы

**Способ установки**: поищите «n8n» в магазине 1Panel и поставьте одним кликом.

Сяомин открыл редактор n8n. Слева — всевозможные ноды: HTTP-запросы, scheduled-триггеры, ![image-20260303152359300](/images/Advanced/image-20260303152359300.png)отправка email, GitHub, Slack... Перетащите ноду «Scheduled Trigger» на канвас, затем ноду «GitHub», соедините линией — и воркфлоу готов. Без кода — только drag, drop и настройка.



Воркфлоу n8n редактируются визуально через drag-and-drop, код писать не нужно. Можно считать, что вы «поселили на сервер дворецкого-автоматизатора».

Поставив n8n, Сяомин собрал простой воркфлоу: каждое утро в 9:00 автоматически проверять, есть ли новые Issue в его GitHub-репозитории, и если есть — слать сообщение на почту. «Раньше я проверял, только когда случайно вспоминал. Теперь само прилетает прямо передо мной».

## Bitwarden: менеджер паролей

**Строка-введение**: опенсорсный сервис управления паролями, self-hosted аналог 1Password.

**Зачем нужен**:

- Все пароли хранятся на вашем сервере, без зависимости от третьих лиц
- Поддержка браузерных расширений и мобильных приложений
- Автозаполнение паролей и генерация надёжных
- Синк между устройствами

**Способ установки**: поищите «Bitwarden» в магазине 1Panel и поставьте одним кликом.

::: warning Замечание
Bitwarden из магазина — на самом деле Vaultwarden (лёгкая реализация Bitwarden на Rust). Полнофункционален, но ест меньше ресурсов.
:::

## Alist: файловый менеджер

**Строка-введение**: приложение для управления файлами, позволяющее собраться с разными облаками и локальными хранилищами в одном месте.

**Что умеет**:

- Просматривать и скачивать файлы на сервере через веб-страницу
- Маунтить Aliyun Drive, Baidu Netdisk, OneDrive и прочие
- Онлайн-превью картинок, видео и документов
- Работать как простой сервис шеринга файлов

**Способ установки**: поищите «Alist» в магазине 1Panel (официальное имя — AList) и поставьте одним кликом. При установке можно настроить порт WebUI (дефолт 5244) и порт S3 (дефолт 5246). После установки зайдите на страницу «Containers» в 1Panel, найдите контейнер AList, кликните подключение к терминалу и выполните `./alist admin random` для генерации случайного пароля (или `./alist admin set YOUR_PASSWORD` для ручной установки), затем залогиньтесь с этим паролем.

Поставив Alist, Сяомин по инструкции сгенерировал админ-пароль в терминале контейнера и вошёл. Сначала он замаунтил локальный каталог на сервере, затем подключил аккаунт Aliyun Drive. Открыв веб-интерфейс Alist, он увидел два источника хранилища бок о бок. Можно кликнуть, полистать файлы и посмотреть превью картинок и видео онлайн. Он отправил URL Alist другу: «Смотри, я собрал собственное облачное хранилище».

Когда файлы разбросаны по Aliyun Drive, Baidu Netdisk, OneDrive и другим местам, для поиска чего-то нужно логиниться в каждое и копаться — Alist собирает всё на одной странице, чтобы листать как в едином файловом менеджере.
