# Core Concepts & Paradigm Evolution

> Прежде чем браться за инструменты, поймите, в какую игру вы играете.

Эта категория покрывает фундаментальные концепции, нужные для навигации в ландшафте AI-ассистированной разработки. От понимания того, чем AI-агенты являются на самом деле, до различия между случайным «vibe coding» и дисциплинированной «agentic engineering».
