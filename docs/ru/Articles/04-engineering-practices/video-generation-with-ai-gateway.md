# Генерация видео через AI Gateway

**Оригинал: [Video Generation with AI Gateway](https://vercel.com/blog/video-generation-with-ai-gateway) (Jerilyn Zheng)**

## Зачем генерация видео в AI Gateway?

Генерация видео быстро эволюционировала от исследовательской диковинки до продакшн-возможности. К 2026-му несколько провайдеров дают API для генерации качественного видео из текстовых промптов, изображений-референсов и существующих футажей. Но как в ранние дни LLM API, у каждого провайдера свой SDK, схема аутентификации, формат ответа и модель ценообразования.

AI Gateway от Vercel решает это так же, как решил фрагментацию LLM-провайдеров: **единый API, абстрагирующий различия**, с финезерненным контролем разработчика над качеством, стоимостью и производительностью. Напишите код генерации видео один раз — и переключайтесь между провайдерами (или используйте несколько одновременно) без изменения кода приложения.

## Интеграция с AI SDK 6

AI SDK 6 вводит first-class-примитивы генерации видео, зеркалящие паттерны, уже привычные по генерации текста и изображений:

### `generateVideo`

Синхронный API для коротких видео:

```typescript
import { generateVideo } from 'ai';
import { gateway } from '@ai-sdk/gateway';

const result = await generateVideo({
  model: gateway('video-model'),
  prompt: 'A product demo showing a user navigating a dashboard app',
  aspectRatio: '16:9',
  duration: 10,
});
```

### `streamVideo`

Для длинного контента или realtime-превью стриминговый API даёт прогрессивный вывод:

```typescript
import { streamVideo } from 'ai';
import { gateway } from '@ai-sdk/gateway';

const stream = streamVideo({
  model: gateway('video-model'),
  prompt: 'An educational walkthrough of setting up a Next.js project',
  aspectRatio: '16:9',
  duration: 60,
});

for await (const chunk of stream) {
  // Progressive frames or segments
  await processVideoChunk(chunk);
}
```

Дизайн API следует паттернам `generateText` и `streamText`, мгновенно знакомым пользователям AI SDK.

## Поддерживаемые провайдеры и модели

AI Gateway даёт доступ к нескольким провайдерам генерации видео через единый интерфейс:

- **High-fidelity-модели**: Для кинематографичного качества, маркетингового контента и полированного вывода
- **Быстрые модели**: Для превью, прототипирования и realtime-приложений
- **Специализированные модели**: Для кейсов вроде улучшения записей экрана, talking head-генерации или анимации

Выбор провайдера автоматический (Gateway выбирает по требованиям качество/скорость) или явный (указываете точную модель). Gateway обрабатывает аутентификацию, форматирование запросов и нормализацию ответов для каждого провайдера.

## Ключевые возможности

### Консистентность персонажей

Одна из сложнейших задач генерации видео — поддержание облика персонажа между кадрами и сценами. AI Gateway решает reference-базированной генерацией:

```typescript
const result = await generateVideo({
  model: gateway('video-model'),
  prompt: 'The character explains a feature while pointing at a whiteboard',
  characterRef: previousScene.characterEmbedding,
  styleRef: brandStyleGuide,
});
```

Передача эмбеддингов персонажа между вызовами генерации поддерживает визуальную консистентность многосценного видео без ручного вмешательства.

### Синхронизация аудио

Сгенерированному видео часто нужно синхронизированное аудио — наррация, звуковые эффекты или фоновая музыка. AI Gateway поддерживает мультимодальную генерацию:

```typescript
const result = await generateVideo({
  model: gateway('video-model'),
  prompt: 'Product walkthrough with narration',
  audio: {
    narration: 'Welcome to our new dashboard. Let me show you...',
    voice: 'professional-female',
    music: 'subtle-corporate',
  },
});
```

Аудио синхронизируется с визуальным контентом в момент генерации, не пришивается после. Это даёт значительно более естественные результаты — lip sync совпадает с наррацией, эффекты — с действиями на экране, переходы музыки следуют сменам сцен.

### Перенос стиля

Применяйте единый визуальный стиль ко всему сгенерированному контенту:

```typescript
const result = await generateVideo({
  model: gateway('video-model'),
  prompt: 'Team collaboration scene in a modern office',
  style: {
    reference: './brand-style.png',
    colorPalette: 'brand-colors',
    mood: 'professional-warm',
  },
});
```

Это обеспечивает брендовую консистентность библиотеки сгенерированных видео без стилевых инструкций в каждом промпте.

## Паттерны стриминга для видео

Стриминг видео требует иных паттернов, чем стриминг текста:

- **Сегментный стриминг**: Видео приходит играемыми сегментами (обычно по 2–5 секунд), отображаемыми прогрессивно
- **Preview-стриминг**: Сначала приходят превью низкого разрешения, за ними high-res сегменты — быстрая визуальная валидация
- **Прогрессивное улучшение**: Сначала проход низкого качества, затем улучшение до финального. Юзеры могут прервать рано, если направление неверное, экономя стоимость

Эти паттерны особенно важны для интерактивных приложений, где юзер ревьюит и апрувит контент до публикации.

## Стоимость и производительность

Генерация видео значительно дороже текста и изображений. Практические стратегии управления:

- **Превью до коммита**: Сначала генерируйте превью низкого разрешения. Полное качество — только после апрува.
- **Оптимизация длительности**: Генерируйте только нужное. 5-секундный продукт-шот дешевле 30-секундной сцены.
- **Кэширование**: AI Gateway кэширует идентичные запросы. Генерируете одну и ту же интро-последовательность — она подаётся из кэша.
- **Батч-обработка**: Ставьте несрочные генерации в очередь на off-peak-цены, где провайдеры это предлагают.

Производительность сильно варьируется по модели и качеству:

- **Быстрые модели**: 10–30 секунд на 10-секундный клип в 720p
- **High-quality-модели**: 2–5 минут на 10-секундный клип в 1080p с аудио-синком
- **Кинематографичные модели**: 10–30 минут на сложные сцены с консистентностью персонажей

## Кейсы

### Маркетинговый контент

Генерируйте продукт-демо, клипы для соцсетей и промо-ролики на масштабе. Консистентность персонажей и перенос брендового стиля делают практичным создание целостной контент-библиотеки без видеопродакшн-команды.

### Демо продуктов

Создавайте walkthrough'и и демонстрации фич из текстовых описаний. Особенно мощно в комбинации с входами записей экрана — начните с реальной записи и дайте AI усилить её наррацией, аннотациями и переходами.

### Образовательные материалы

Генерируйте обучающие видео, визуальные объяснения и туториалы. Стриминговый API включает интерактивный образовательный опыт, где контент генерируется в ответ на вопросы студентов.

### Персонализированный контент

Создавайте видео на юзера или сегмент. SaaS-onboarding может генерировать персонализированное приветственное видео, ссылающееся на конкретную конфигурацию продукта юзера.

## Практические советы

1. **Начните с текста**: Напишите детальный сценарий до генерации видео. Чем лучше текстовый промпт, тем лучше вывод — как с LLM.
2. **Используйте референс-изображения**: Где возможно, давайте визуальные референсы для стиля, персонажей и сцен. Reference-генерация контролируемее чисто текстовой.
3. **Итерируйте на коротких клипах**: Тестируйте промпты и настройки на 3–5-секундных клипах до генерации полного контента.
4. **Планируйте пост-обработку**: AI-видео часто выигрывает от лёгкого монтажа — обрезка, цветокоррекция, выравнивание аудио. Встройте это в воркфлоу.
5. **Мониторьте расходы**: Настройте бюджетные алерты в AI Gateway. Стоимость генерации видео накапливается быстро, особенно при итерациях по промптам в разработке.
6. **Кэшируйте агрессивно**: Если часть видеоконтента переиспользуема (интро, аутро, переходы) — сгенерируйте один раз и компонуйте с динамическим контентом.
