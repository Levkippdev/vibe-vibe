# C. Карточка быстрой справки по UI

Эта страница — не урок теории дизайна, а просто набор практичных терминов выражения, достаточных для базового уровня. Когда вы в главе 3 правите interface и не можете найти нужные слова, приходите сюда за формулировками.

## Термины направления стиля

| Ощущение, которое хотите | Можно сказать так |
|------|--------------|
| Минимализм и профессионализм | Чисто, сдержанно, информация на первом месте, ясная иерархия |
| Тепло и дружелюбие | По-человечески, располагает к контакту, расслабленно, не деревянно |
| Лёгкая tech-ориентированность | Свежо, цифровое ощущение, чуть футуризма, но без выпендрёжа |
| Больше похоже на продуманный проект | Не как дефолтный шаблон, ясные приоритеты, визуальный фокус |

## Термины выражения цвета

| Что хотите передать | Можно сказать так |
|------|--------------|
| Чисто и светло | Светлые тона, воздух, свежесть, много whitespace |
| Стабильно и сдержанно | Низкая насыщенность, чуть темнее, не слишком кричаще |
| С акцентным цветом | Только один основной цвет, остальное придержать |
| Не слишком пёстро | Избегай лишних градиентов и не дай цветам прыгать случайно |

## Термины layout и иерархии

| Проблема | Можно сказать так |
|------|--------------|
| Страница ощущается слишком разрозненной | Первый экран слишком разрозненный; усиль визуальную иерархию |
| Страница ощущается слишком тесной | Секции слишком сбиты; добавь больше whitespace и воздуха |
| Фокус неясен | Сделай имя, представление в одну строку и главную кнопку заметнее |
| Ощущается как плоская информация | Создай больше различий между заголовком, основным текстом и пояснениями |

## Термины взаимодействия и опыта

| Цель | Можно сказать так |
|------|--------------|
| Дать посетителям понять, кто вы | Посетитель должен с одного взгляда на первый экран понимать, кто я |
| Сделать вход в чат заметнее | Сделай вход в чат более заметным, но не подавляющим страницу |
| Чтобы кнопки ощущались реально кликабельными | Дай главной кнопке ясный feedback и реальное назначение |
| Поддержать и мобильный | Позаботься, чтобы текст читался на мобильном и секции не накладывались |

## Очень практичный шаблон описания interface

```text
Проблема текущей страницы: ______
Хочу, чтобы ощущение стало таким: ______
Пока поменяй только эти части: ______
А эти части не трогай: ______
```

Если вы можете ясно объяснить «проблема + ощущение + границы», этого обычно уже достаточно.
