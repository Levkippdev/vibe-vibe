# D. Карточка минимальных действий Git

В базовой версии Git не занимается полным workflow коллаборации. Он делает три вещи: сохраняет snapshot, показывает историю и откатывает. Считайте его «кнопкой отката» проекта — этого достаточно.

## 1. Сохранить snapshot: отметить текущую стабильную версию

Подходящий сценарий: перед крупными правками.

Можно прямо попросить AI так:

```text
Я собираюсь начать довольно крупный раунд правок.
Сначала помоги создать минимальный snapshot текущего проекта
как версию, к которой я смогу откатиться.
Скажи только шаги, которые нужны мне в этот раз, — без теории Git.
```

## 2. Посмотреть историю: проверить, какие версии уже сохранены

Подходящий сценарий: вы уже сделали несколько раундов правок и хотите знать, куда ещё можно откатиться.

Можно спросить так:

```text
Помоги посмотреть, какие snapshot-записи сейчас есть в этом проекте.
Хочу знать, какие ближайшие точки отката.
```

## 3. Откатиться: если раунд правок всё сломал — вернуться на стабильную версию

Подходящий сценарий: layout сломан, контент превратился в кашу или страница явно деградировала.

Можно сказать так:

```text
Результат этого раунда правок плохой.
Помоги вернуться к предыдущей стабильной версии и скажи,
к какой точке snapshot этот откат вернулся.
```

## Минимальная ментальная модель

| Действие | Как о нём думать сейчас |
|------|--------------------|
| Сохранить один раз | Отметить текущую версию точкой, к которой можно «вернуться» |
| Посмотреть историю | Увидеть, какие точки вы сохраняли раньше |
| Откатиться | Вернуться в ближайшее стабильное состояние, когда что-то пошло не так |

## Самое важное напоминание базовой версии

Не ждите, пока проект уже сломается, чтобы впервые вспомнить о Git. Более безопасный порядок: **сначала сохранитесь — потом делайте смелые правки**.
