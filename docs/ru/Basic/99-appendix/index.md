# Приложения

Приложения — ни подготовительное задание, ни вторая книга для чтения от корки до корки. Это скорее ящик с инструментами: идите по главному пути в основном тексте, а сюда возвращайтесь по мере необходимости — когда застряли, забыли, как сформулировать, как спросить или как откатиться.

## Как выжать из приложений максимум пользы

Если вы уже двигаете проект по основному тексту, лучший подход — не «читать от A до G», а приходить с конкретной проблемой.

- Не знаете, как писать требования — начните с `A`
- Наткнулись на ошибку — начните с `B`
- Застряли на interface — смотрите `C`
- Готовитесь к крупной правке — сначала прочитайте `D`
- Перед подключением API или запуском — сначала `E`
- Когда оцениваете границы проекта — идите в `F`
- Хотите более системного углубления — идите в `G`

При таком использовании приложения становятся ускорителем, а не дополнительной нагрузкой.
