# Гайд по приватному deploy

::: warning Активная фаза обновлений
Туториал сейчас находится в фазе **быстрых обновлений**: после deploy может вскоре выйти новая версия. Рекомендуется периодически подтягивать свежий код и пересобирать сайт, чтобы контент оставался актуальным.
:::

Этот гайд описывает, как выполнить приватный (on-premise) deploy сайта VibeVibe в сети предприятия.

## Обзор проекта

VibeVibe — статический сайт на **VitePress**, полностью автономный, без вызовов внешних API. Это делает приватный deploy очень простым — достаточно выложить собранные файлы на внутренний сервер.

### Tech stack

| Технология | Версия | Назначение |
|------|------|------|
| VitePress | 1.6.4 | генератор статических сайтов |
| Vue | 3.5.25 | frontend-фреймворк |
| Node.js | рекомендуется 24 LTS | среда сборки |

## Способы deploy

### Способ 1: deploy статических файлов напрямую (рекомендуется)

Самый простой путь, подходит для большинства сценариев.

```bash
# 1. Клонируем проект
git clone https://github.com/datawhalechina/vibe-vibe.git
cd vibe-vibe

# 2. Устанавливаем зависимости
pnpm install

# 3. Собираем статический сайт
pnpm build

# 4. Результат сборки лежит в docs/.vitepress/dist
# Скопируйте всю папку dist на свой web-сервер
```

После сборки каталог `docs/.vitepress/dist` содержит все статические файлы; их можно выложить на:

- **Nginx**: просто укажите на каталог dist
- **Apache**: настройте DocumentRoot
- **IIS**: сделайте каталог dist корневым каталогом сайта
- **Object storage**: загрузите в OSS/S3 и включите static website hosting
- **Любой другой static hosting**

### Способ 2: через Docker (рекомендуется)

С Docker проще всего — Nginx уже встроен в контейнер, сервер запускается одной командой:

```dockerfile
# Dockerfile
FROM node:24-alpine AS builder

WORKDIR /app

# Устанавливаем pnpm
RUN npm install -g pnpm

# Копируем package.json и lock-файл
COPY package.json pnpm-lock.yaml ./

# Устанавливаем зависимости
RUN pnpm install --frozen-lockfile

# Копируем файлы проекта
COPY . .

# Собираем
RUN pnpm build

# Раздаём статику через Nginx
FROM nginx:alpine
COPY --from=builder /app/docs/.vitepress/dist /usr/share/nginx/html
EXPOSE 80
```

```bash
# Собираем образ
docker build -t vibevibe-docs .

# Запускаем контейнер (доступен на http://localhost:8080)
docker run -d -p 8080:80 vibevibe-docs
```

**Плюс**: Nginx уже встроен в контейнер, ничего донастраивать не нужно, сервис поднимается одной командой.

### Способ 3: через EdgeOne Pages (Tencent Cloud)

Если вы пользуетесь Tencent Cloud EdgeOne Pages, deploy в один клик:

1. Создайте статический сайт в консоли EdgeOne
2. Настройте автосинхронизацию с GitHub-repository
3. Каждый push автоматически пересобирает сайт

### Способ 4: локальный preview

После сборки можно посмотреть сайт локально:

```bash
pnpm preview
# Откройте http://localhost:4173
```

## Нюансы офлайн-среды

Поскольку это статический сайт, после приватного deploy он работает **полностью офлайн** — интернет-соединение не требуется.

### Ресурсы, которые, возможно, придётся обработать

1. **Система комментариев Giscus** (если используется):
   - Для загрузки требуется интернет
   - Рекомендация: при приватном deploy отключить её или поднять собственную систему комментариев

2. **Картинки**:
   - Сейчас используются raw-ссылки GitHub
   - Рекомендация: скачайте изображения локально в каталог `docs/public/`

3. **Внешние CDN**:
   - Сейчас часть ресурсов может грузиться с CDN
   - Рекомендация: инлайните ресурсы при сборке или используйте внутреннее зеркало

## Шаги сборки в полностью офлайн-среде

Как собрать в среде без интернета:

```bash
# 1. На машине с интернетом скачайте проект
git clone https://github.com/datawhalechina/vibe-vibe.git

# 2. Упакуйте проект (вместе с node_modules)
tar czf vibe-vibe.tar.gz vibe-vibe/

# 3. Перенесите на офлайн-сервер и распакуйте
tar xzf vibe-vibe.tar.gz

# 4. Если node_modules неполон, установите заново
cd vibe-vibe
# используйте локальный npm-репозиторий или офлайн-пакеты
```

## FAQ

### Q: Нужна ли database?

Нет. VibeVibe — чисто статический сайт, весь контент предварительно сгенерирован из Markdown-файлов.

### Q: Нужен ли собственный домен?

Нет. Можно заходить по внутреннему IP, например `http://192.168.1.100:8080`.

### Q: Работает ли поиск?

Да. Встроенный в VitePress клиентский поиск полностью работает офлайн.

### Q: Как обновлять контент?

```bash
# 1. Подтяните свежий код
git pull

# 2. Пересоберите
pnpm build

# 3. Замените каталог dist
```

### Q: Что делать, если сборка падает?

```bash
# Почистите кэш и пересоберите
rm -rf node_modules docs/.vitepress/cache
pnpm install
pnpm build
```

## Рекомендации по приватному deploy

### Усиление безопасности

1. **Уберите комментарии**: отключите Giscus в конфигурации
2. **Внутренний контур**: сайт должен быть доступен только во внутренней сети компании, не публикуйте его в интернет
3. **Контроль доступа**: настройте basic auth в Nginx или интегрируйте корпоративный SSO

### Кастомизация контента

Если нужно адаптировать контент туториала (например, добавить внутренние кейсы компании), правьте Markdown-файлы напрямую и пересобирайте сайт.
