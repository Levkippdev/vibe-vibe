# Workbook — маршрут обучения Vibe Vibe (русская версия)

Открывай только текущий урок. Если хочется что-то добавить или улучшить в проекте — запиши это в Parking lot артефакта текущего урока и вернись к шагу.

## Как устроено обучение

- Источник правды о прогрессе: [`PROGRESS.md`](PROGRESS.md).
- Урок ведёт коуч по steps-файлу: [`steps/`](steps/).
- Твоё рабочее место: [`my-work/`](my-work/) — артефакты уроков.
- Веб-версия уроков (параллельное чтение): `http://localhost:5173/ru/...` (ветка `ru`, `pnpm dev`).

## Маршрут Basic (главы 0–1 переведены)

| Урок | Цель | Урок пройден, когда |
|---|---|---|
| 0.0 Добро пожаловать в «Основы» | Понять, что строим и как учиться | Ты можешь сказать, что соберёшь и какой маршрут выбрал |
| 0.1 Чему учит туториал | Увидеть позиционирование и конечную цель | Ты перечислил 3 навыка курса и знаешь, чем он НЕ является |
| 0.2 Для кого курс | Решить, подходит ли тебе путь | Ты выбрал свой learning-путь (hands-on / полный / скачущий) |
| 0.3 Что делать при затыке | Освоить единый workflow помощи | Ты заполнил шаблон «Что я сделал → Проблема → Хотел» |
| 0.4 Карта обучения | Увидеть весь маршрут глав | Чек-лист главы 0 закрыт |
| 1.0 Первая версия | Настроиться на «сначала собрать» | Ты знаешь, что v1 — это начало, а не финал |
| 1.1 Подготовка материалов | Собрать первую партию фактов о себе | Артефакт «материалы» заполнен (5 групп) |
| 1.2 Шаблон требований | Превратить факты в требования | Заполненный шаблон требований готов к вставке в AI-инструмент |
| 1.3 Генерация + 3 раунда доводки | Собрать v1 и довести до зачёта | v1 открывается, чат-зона есть, чек-лист приёмки 1.4 пройден |
| 1.4 Приёмка и backlog | Зафиксировать проблемы и план | Чек-лист оптимизации записан в артефакт |
